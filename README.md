# Python - Lógica e Exercícios

Este repositório reúne exercícios práticos de lógica de programação desenvolvidos em Python durante meus estudos em Ciência da Computação.

## Objetivo

Consolidar os fundamentos da programação por meio da resolução de problemas, aplicação de estruturas de controle e construção de pequenos sistemas.

## Conteúdo abordado

- Estruturas condicionais (if, elif, else)
- Estruturas de repetição (for, while)
- Operadores aritméticos e lógicos
- Controle de fluxo
- Jogos simples
- Mini sistemas baseados em lógica

## Estrutura

Os arquivos estão organizados por desafios e exercícios progressivos, representando a evolução do aprendizado ao longo do tempo.

- Python
